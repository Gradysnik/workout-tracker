# Настройка

Разовая настройка, чтобы приложение могло входить в Google и чтобы GitHub собирал подписанный APK. Занимает около 20 минут.

## 1. Ключ подписи APK

Вход через Google привязан к подписи APK, поэтому ключ создаётся один раз и хранится вне репозитория.

```bash
brew install openjdk@17
```

```bash
mkdir -p ~/.workout-tracker && /opt/homebrew/opt/openjdk@17/bin/keytool -genkeypair -v -keystore ~/.workout-tracker/release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias release
```

Команда спросит пароль и имя. Пароль запомните: он понадобится в шаге 3. Сохраните копию файла `release.jks` в надёжном месте. Если ключ потерять, новую версию нельзя будет установить поверх старой.

Отпечаток SHA-1 для шага 2:

```bash
/opt/homebrew/opt/openjdk@17/bin/keytool -list -v -keystore ~/.workout-tracker/release.jks -alias release | grep SHA1
```

## 2. Проект в Google Cloud

Названия пунктов меню в консоли Google иногда меняются; ориентируйтесь по смыслу.

1. Откройте <https://console.cloud.google.com/> и создайте проект, например `workout-tracker`.
2. В разделе **APIs & Services → Library** включите **Google Sheets API** и **Google Drive API**.
3. В разделе **Google Auth Platform** (раньше «OAuth consent screen»):
   - **Branding**: название приложения и ваш email.
   - **Audience**: тип **External**, затем **Publish app**, чтобы статус стал **In production**. Проверка Google не потребуется: приложение запрашивает только доступ к файлам, которые само создало.
   - **Data Access**: добавьте область `https://www.googleapis.com/auth/drive.file`.
4. В разделе **Clients** создайте два клиента OAuth:
   - тип **Android**: имя пакета `com.gradysnik.workout_tracker`, отпечаток SHA-1 из шага 1;
   - тип **Web application**: без дополнительных настроек. Скопируйте его **Client ID** (заканчивается на `.apps.googleusercontent.com`) — он нужен в шаге 3.

## 3. Секреты репозитория

В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret**. Нужны пять секретов:

| Имя | Значение |
|---|---|
| `KEYSTORE_BASE64` | вывод команды `base64 -i ~/.workout-tracker/release.jks` |
| `KEYSTORE_PASSWORD` | пароль хранилища из шага 1 |
| `KEY_PASSWORD` | пароль ключа (обычно тот же) |
| `KEY_ALIAS` | `release` |
| `GOOGLE_SERVER_CLIENT_ID` | Client ID веб-клиента из шага 2 |

## 4. Сборка APK

Создайте тег версии и отправьте его:

```bash
git tag v0.1.0 && git push origin v0.1.0
```

Через несколько минут APK появится на странице **Releases** репозитория. Скачайте его на телефон и установите (Android попросит разрешить установку из этого источника).

## 5. Первый запуск и перенос истории

1. Откройте приложение, зайдите в настройки (шестерёнка) и нажмите **Войти через Google**. Приложение создаст в вашем Google Диске таблицу **Workout Tracker** с листами «Программа», «Расписание» и «Журнал».
2. На ноутбуке выгрузите старую таблицу: **Файл → Скачать → CSV**.
3. Преобразуйте её:

   ```bash
   dart run tool/migrate.dart ~/Downloads/старая-таблица.csv ~/Downloads/migrated
   ```

   Получатся файлы `program.csv`, `schedule.csv` и `journal.csv`. Скрипт напечатает ячейки, которые не смог разобрать.
4. В таблице **Workout Tracker** откройте лист «Программа», затем **Файл → Импорт → Загрузка**, выберите `program.csv` и вариант **Заменить текущий лист**. Повторите для «Расписание» (`schedule.csv`) и «Журнал» (`journal.csv`).
5. В приложении: **Настройки → Восстановить из таблицы**.

## Как править программу

- Листы «Программа» и «Расписание» правятся в таблице. Приложение читает их при запуске и по жесту «потянуть вниз» на экране «Сегодня».
- **Замена упражнения**: впишите новое название вместо старого. У нового упражнения прогресс начнётся с нуля, старое останется в «Истории → Архив упражнений».
- **Исправление опечатки** в названии тоже создаёт «новое» упражнение. Чтобы сохранить историю, замените название и в листе «Журнал» (Правка → Найти и заменить), затем выполните «Восстановить из таблицы».
- Тип упражнения: `силовое`, `время` или `кардио`. Дроп-сет: `да` или `нет`.
- Диапазон повторов пишите через длинное тире (`8–10`) или как текст: запись `8-10` таблица может превратить в дату.
- Лист «Журнал» ведёт приложение. Ручные правки в нём попадут в приложение только после «Восстановить из таблицы».
